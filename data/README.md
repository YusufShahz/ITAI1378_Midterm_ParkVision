# Dataset

**Name:** PKLot – Parking Lot Dataset  
**Source:** https://universe.roboflow.com/search?q=pklot  
**Size:** ~12,000 labeled images  
**Classes:** `occupied`, `empty`  
**Format:** YOLOv8 (bounding boxes)  
**Split:** 70% train / 15% val / 15% test

## How to Download

pip install roboflow

Then run the download cell in notebooks/01_exploration.ipynb.

> Note: Raw data files are NOT committed to this repo.
> Add /data/images/ and /data/labels/ to your .gitignore.
